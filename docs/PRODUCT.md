# 케어롯 CareRoute 서비스 설계

케어롯은 차량 상태와 운전자 직접 확인을 연결하는 승하차·인계 지원 앱입니다. 첫 타깃은 교통약자를 이동 지원하는 복지시설 운전자와 동행자입니다. 고객 불편과 지불 의사는 아직 현장 검증이 필요한 가설입니다.

## 핵심 장면

승객이 내리고 문이 닫혔지만 보호자는 아직 도착하지 않았습니다. 차량은 문 닫힘을 알 수 있고, 운전자는 실제 사람의 인계 여부를 알 수 있습니다. 앱은 두 정보를 분리하여 인계 대기 상태를 유지하고 직접 확인 후 기록을 마칩니다.

## 공모전 기준과의 연결

| 기준 | 설계 선택 | 확인할 근거 |
|---|---|---|
| 차량특화성 | 기어·도어 관측에 따라 입력 가능 상태 변경 | Pleos 콘솔의 P/D·RR door 변경 시연 |
| 창의성 | 문 닫힘과 사람의 인계를 별도 상태로 처리 | 문을 먼저 닫아도 완료되지 않는 장면 |
| 기술 활용성 | SDK Capability·Get·Listener와 CarUxRestrictions | 실제 코드, 실행 APK, 검증 기록 |
| 사업성 | 복지시설 이동 지원 업무에서 반복 사용 | 현장 관찰, 기관 파일럿, 구독 지불 의사 검증 계획 |

## 고객 검증 계획

복지시설 운전자·동행자·보호자를 대상으로 최근 승하차 한 건의 실제 흐름을 듣고, 어떤 확인을 누구에게 전달하는지 관찰합니다. 질문은 ‘이 앱이 좋은가’보다 ‘현재 무엇을 기록하고, 어디서 잊거나 중복 입력하는가’에 집중합니다. 이용자의 건강 정보나 신원을 수집하지 않고 업무 흐름부터 검증합니다.

초기 가정은 기관2곳·운전자20명, 월 사용률70%에 따른14MAU, 4주 유지율60%입니다. 모두 검증 목표이며 실제 성과가 아닙니다. 확인 누락·입력 시간·반복 사용률을 측정하고 차량별 구독 또는 기관 도입 가격에 대한 지불 의사를 확인합니다.

## 단계별 확장

1. 현재: 가상 승객1명, 가상 목적지1곳, 읽기 전용 차량 신호, 직접 확인 기록.
2. 현장 파일럿: 승객별 지원 메모, 운행별 기록 분리, 삭제·보관 정책과 접근성 검증.
3. 후속: 다중 승객, 실제 운행·내비 연동, 동의 기반 보호자 인계 공유.

실제 승객·보호자 신원 인증, 휠체어 고정 감지, 위험 상황 자동 판정, 차량 출발 제어는 현재 구현 범위에 포함되지 않습니다. 앱의 확인 기록은 운전자가 입력한 기록이며 안전 상태를 인증하는 자료가 아닙니다.
